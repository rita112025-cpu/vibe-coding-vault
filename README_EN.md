# 30 Best Free Dev & Design Resources - Vibe Coding Vault

> 30 free open-source dev & design resources with bilingual support, ready for GitHub Pages.

## Features
- Notion-style UI
- Search + Category filter
- Bilingual toggle (ZH/EN)
- 30 clickable resources
- 100% static, no backend

## Deploy to GitHub Pages
1. Push to GitHub
2. Settings > Pages > Source: main / root
3. Visit https://<user>.github.io/<repo>/

See `data/resources.json` for full data.
